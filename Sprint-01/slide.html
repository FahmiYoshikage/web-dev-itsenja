02. Dokumen HTML5
03 / 18

Anatomi Baku Dokumen HTML5

Setiap file HTML valid wajib mengikuti struktur dasar standar W3C berikut:

<!DOCTYPE html>
<html lang="id">
  <head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Judul Website</title>
  </head>
  <body>
    <h1>Konten Terlihat di Layar</h1>
  </body>
</html>

Penjelasan Elemen Kunci:

  • <!DOCTYPE html>: Mendeklarasikan standar dokumen HTML5 ke browser.
  • <html lang="id">: Root elemen utama dan bahasa konten.
  • <head>: Metadata, link stylesheet font, dan judul tab.
  • <meta name="viewport" ...>: Menjamin tampilan skala responsif di smartphone.
  • <body>: Seluruh konten visual yang ditampilkan ke user.
03. Tipografi & Teks
04 / 18

Heading, Paragraf & Format Teks

Heading (<h1> hingga <h6>) menyusun struktur hierarki informasi penting, sedangkan <p> digunakan untuk blok teks bacaan.

Heading Hierarchy

Hanya boleh ada 1 tag <h1> per halaman untuk judul utama topik. Sub-topik menggunakan <h2>, dan rincian bagian menggunakan <h3>.

Formatting Tag

• <strong>: Teks penting (tebal)
• <em>: Penekanan makna (miring)
• <code>: Cuplikan baris kode
• <mark>: Sorotan kuning teks

Line Break & Divider

• <br>: Ganti baris tunggal (self-closing)
• <hr>: Garis horizontal pemisah tema konten

05. Hyperlink
06 / 18

Hyperlink: Menghubungkan Halaman Web

Tag anchor <a href="..."> membuat web saling terhubung (World Wide Web).

1. Absolute URL

Menuju website eksternal di internet.

<a href="https://github.com" target="_blank">GitHub</a>
2. Relative URL

Menuju file halaman internal project.

<a href="about.html">Tentang Kami</a>
3. Anchor ID & Email

Melompat ke bagian tertentu atau kontak.

<a href="#kontak">Kontak</a>
<a href="mailto:me@mail.com">Email</a>
Best Practice Keamanan: Saat menggunakan target="_blank" untuk membuka tab baru, selalu tambahkan atribut rel="noopener noreferrer" demi alasan keamanan.
06. Media Konten
07 / 18

Media Gambar: Tag <img> & Aksesibilitas

Tag <img> adalah elemen self-closing untuk menampilkan gambar di halaman web.

Atribut Wajib & Esensial:

  • src="...": Lokasi sumber path gambar (lokal atau URL online).
  • alt="...": Deskripsi teks alternatif gambar (sangat krusial untuk screen-reader tuna netra & saat gambar gagal dimuat).
  • width & height: Menentukan dimensi aspek rasio untuk mencegah pergeseran layout (CLS).

Elemen <figure> & <figcaption>:

Gunakan pembungkus semantik untuk gambar yang memiliki keterangan teks di bawahnya:

<figure>
  <img src="foto.jpg" alt="Foto Profil">
  <figcaption>Foto Profil Pengembang</figcaption>
</figure>

08. Pengelompokan List
09 / 18

Lists: Unordered & Ordered List

HTML menyediakan 2 jenis list utama untuk mengorganisir daftar data atau langkah berurutan.

Unordered List (<ul>)

Daftar tanpa urutan numerik (menggunakan bullet point).

<ul>
  <li>HTML5</li>
  <li>CSS3</li>
  <li>JavaScript</li>
</ul>
Ordered List (<ol>)

Daftar dengan urutan nomor/huruf yang runtut.

<ol>
  <li>Tahap Analisis Desain</li>
  <li>Menulis Kerangka HTML</li>
  <li>Styling dengan CSS</li>
</ol>
09. Tabel Data
10 / 18

Struktur Tabel Data Terstruktur (<table>)

Tabel digunakan untuk menampilkan kumpulan data baris dan kolom yang terukur.

1. <table>

Elemen wadah pembungkus tabel.

2. <thead> & <tbody>

Pemisah header tabel dan data body.

3. <tr>

Table Row (mendefinisikan satu baris horizontal).

4. <th> & <td>

<th> = Header Kolom, <td> = Data Sel.

Penting: Jangan gunakan tag <table> untuk membuat layout website! Gunakan CSS Flexbox/Grid untuk tata letak, dan gunakan tabel khusus untuk data tabular.

11. Form & Input
12 / 18

Formulir & Input Interaktif (<form>)

Formulir memungkinkan pengguna mengirimkan data ke sistem melalui beragam jenis elemen kontrol input.

Tipe Input Teks

• type="text": Teks umum
• type="email": Validasi email
• type="password": Karakter sensor

Tipe Pilihan

• type="checkbox": Multi-opsi
• type="radio": Pilihan tunggal
• <select>: Dropdown menu

Area Teks & Tombol

• <textarea>: Pesan paragraf
• <button type="submit">: Kirim form

13. Semantic HTML5
14 / 18

Semantic HTML5: Struktur Bermakna

Gantilah penggunaan <div> berlebihan (Div Soup) dengan tag semantik yang memberikan arti jelas bagi mesin pencari dan screen reader.

<header> & <nav>

Kepala dokumen, logo, dan menu navigasi utama situs.

<main> & <section>

Konten utama unik halaman dan pembagian bab tematik.

<article> & <footer>

Konten mandiri (posting/card) dan kaki halaman (hak cipta/kontak).

14. Best Practices
15 / 18

Best Practices: SEO & Web Accessibility

Panduan standar industri agar halaman web mudah ditemukan di Google dan nyaman diakses oleh seluruh pengguna:

Title Tag Unik: Berikan judul <title> yang deskriptif pada setiap halaman.
Wajib Alt Text: Setiap tag <img> wajib memiliki atribut alt yang jelas.
Struktur Heading Runtun: Hindari melompat dari <h1> langsung ke <h4>.
Label pada Form: Setiap input harus dipasangkan dengan tag <label for="...">.
