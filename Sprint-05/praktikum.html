Workshop Interaktif Mandiri

Hands-On Lab: Git, GitHub & Deployment

Panduan praktikum langkah-demi-langkah berbasis web interaktif. Kamu akan menginisialisasi Git, menulis commit standar industri, membuat fitur dengan branching, dan menerbitkan website portofolio ke internet.

1. Repositori Lokal

Inisialisasi repo, status tracking, proteksi file rahasia via .gitignore, dan Atomic Conventional Commits.

2. Feature Branching

Mengisolasi penambahan fitur pada branch baru, memeriksa selisih baris kode (diff), dan melakukan merge ke main.

3. Publikasi Cloud

Menghubungkan ke remote GitHub dan melakukan deployment otomatis live ke internet via GitHub Pages / Vercel.

Petunjuk Penggunaan: Gunakan tombol navigasi [Next] atau tombol panah keyboard [→] untuk mengikuti setiap tahapan hands-on lab. Setiap slide dilengkapi simulator interaktif dan perintah yang dapat disalin dengan 1 klik!

02. Lab 1 — Inisialisasi
03 / 12

Tahap 1: Setup Identitas & Inisialisasi Git

Buka terminal kamu, arahkan ke folder latihan praktikum, konfigurasikan identitas global, lalu aktifkan pelacakan Git dengan git init.

Perintah di Terminal Komputer Kamu:
Terminal / Bash
# 1. Masuk ke direktori latihan $cd Sprint-05/latihan-git # 2. Atur identitas kamu $git config --global user.name "Nama Kamu" $git config --global user.email "email@kamu.com" $git config --global init.defaultBranch main # 3. Inisialisasi repositori Git $git init $git status
Output Terminal Ekspektasi:
Initialized empty Git repository in /project/Sprint-05/latihan-git/.git/

On branch main
No commits yet

Untracked files:
  .gitignore
  app.js
  index.html
  style.css

nothing added to commit but untracked files present (use "git add" to track)
Penjelasan: Warna merah pada git status menandakan file masih berada di Working Directory dan belum dimasukkan ke antrean Staging Area.

07. Lab 6 — Merge
08 / 12

Tahap 6: Menggabungkan Cabang ke Main (Merge)

Setelah fitur selesai dan di-commit pada branch fitur, pindah kembali ke branch main dan satukan perubahan.

Langkah Merge di Terminal Kamu:
Terminal
# 1. Pindah kembali ke main $git switch main # 2. Gabungkan perubahan dari branch fitur $git merge feature/add-sprint03-card # 3. Hapus branch fitur lokal yang sudah selesai $git branch -d feature/add-sprint03-card
Status Visual Pasca-Merge
C1
C2
HEAD -> mainC3

08. Lab 7 — Push Remote
09 / 12

Tahap 7: Menghubungkan ke GitHub Cloud

Simpan riwayat kodinganmu secara aman di cloud dan siap dibagikan ke seluruh dunia dengan menghubungkannya ke GitHub.

Perintah Hubungkan & Push ke GitHub
# 1. Daftarkan URL remote GitHub git remote add origin https://github.com/FahmiYoshikage/web-portfolio-bootcamp.git # 2. Pastikan branch utama bernama main git branch -M main # 3. Kirim seluruh riwayat commit ke GitHub git push -u origin main
Tips: Sebelum menjalankan perintah di atas, pastikan kamu sudah membuat repositori publik baru bernama web-portfolio-bootcamp di github.com/new (biarkan kosong tanpa centang README).
09. Lab 8 — GitHub Pages
10 / 12

Tahap 8: Go Live via GitHub Pages (1 Menit)

Publikasikan websitemu secara instan dan 100% gratis menggunakan fitur bawaan GitHub Pages:

Langkah Konfigurasi di GitHub:
  1. Buka repositori kamu di GitHub > klik tab Settings.
  2. Di bilah navigasi kiri, klik menu Pages.
  3. Di bawah Build and deployment, pilih Deploy from a branch.
  4. Pilih Branch: main dan folder: / (root) > klik Save.
  5. Tunggu 1–2 menit, refresh halaman untuk mendapatkan tautan publik!

Website Kamu Live di Internet!

Format URL publik resmi yang dihasilkan:

https://USERNAME.github.io/web-portfolio-bootcamp/
