01. Konsep Dasar
02 / 17

Apa itu JavaScript sebenarnya?

JavaScript (JS) adalah bahasa pemrograman tingkat tinggi yang berjalan langsung secara native di dalam browser pengguna tanpa perlu compiler manual.

Dijalankan di Runtime Browser

Engine seperti Google V8 (Chrome) dan SpiderMonkey (Firefox) mengeksekusi kode JS langsung menjadi machine code secara Just-In-Time (JIT).

Kolaborasi Tiga Serangkai Web

HTML menyusun struktur semantic, CSS menghias visualisasi, sedangkan JavaScript memberikan nyawa dan kecerdasan interaksi.

Inti Pembelajaran: Jangan menghafal sintaksis secara buta. Pahami bagaimana aliran data bergerak dari logika JS menuju tampilan visual di layar monitor.
02. Integrasi File
03 / 17

Cara Menghubungkan JavaScript ke HTML

Ada dua metode utama untuk menyematkan skrip JavaScript ke dalam berkas HTML.

Metode 1: Inline Script 
<body>
  <h1>Halo Dunia</h1>

  <!-- Ditulis langsung di tag script -->
  <script>
    console.log("Dieksekusi langsung!");
  </script>
</body>
Metode 2: Eksternal Script (Direkomendasikan) 
<body>
  <h1>Halo Dunia</h1>

  <!-- Dipisahkan ke file app.js -->
  <script src="app.js"></script>
</body>
Praktik Terbaik: Letakkan tag <script> persis sebelum penutup </body> agar parser browser selesai membaca seluruh elemen visual HTML sebelum kode JavaScript mulai beroperasi.

04. Variabel & Tipe Data
05 / 17

Variabel = Wadah Penyimpanan Data

Gunakan let untuk variabel yang nilainya dapat diperbarui, dan const untuk nilai konstan yang tidak pernah berubah.

Coba Edit Nilai Variabel Editable ✎ 
let nama = "Fahmi";
let umur = 20;
let statusBelajar = true;

alert("Nama: " + nama + "\nUmur: " + umur + " tahun\nStatus Aktif: " + statusBelajar);

String (Teks)

Rangkaian karakter yang selalu diapit tanda kutip: "ITSENJA" atau 'Frontend'.

Number (Angka)

Bilangan bulat maupun desimal tanpa tanda kutip: 20, 3.14.

Boolean (Kondisi Biner)

Hanya memiliki dua kemungkinan nilai kebenaran logika: true atau false.

05. Logika Percabangan
06 / 17

Pengkondisian: Membuat Keputusan

Program menentukan jalur aksi yang berbeda berdasarkan evaluasi kondisi boolean if, else if, dan else.

Coba Ubah Angka Nilai (misal: 65 atau 90) Editable ✎ 
let nilaiUjian = 85;

if (nilaiUjian >= 80) {
  alert("Nilai kamu " + nilaiUjian + " -> Selamat, kamu LULUS dengan predikat MEMUASKAN! 🎉");
} else if (nilaiUjian >= 70) {
  alert("Nilai kamu " + nilaiUjian + " -> Kamu LULUS KKM! 👍");
} else {
  alert("Nilai kamu " + nilaiUjian + " -> Belum lulus, tetap semangat belajar! 💪");
}
06. Perulangan Logika
07 / 17

Perulangan: Eksekusi Berulang Otomatis

Daripada menulis kode yang sama berulang kali, perulangan for mengeksekusi blok kode sebanyak batas yang ditentukan.

Coba Ubah Batas Akhir Loop (misal: i <= 3 atau 10) Editable ✎ 
let rekapAbsen = "Daftar Kehadiran Siswa:\n";

for (let i = 1; i <= 5; i++) {
  rekapAbsen += "Peserta Bootcamp Antrian #" + i + "\n";
}

alert(rekapAbsen);
07. Modular Function
08 / 17

Function: Blok Logika Reusable

Fungsi membungkus sekumpulan instruksi ke dalam satu modul yang dapat dipanggil berkali-kali dengan argumen parameter yang berbeda.

Definisikan dan Panggil Fungsi Editable ✎ 
// Definisi Function
function hitungTotal(harga, kuantiti) {
  let subtotal = harga * kuantiti;
  return "Subtotal: Rp " + subtotal.toLocaleString("id-ID");
}

// Pemanggilan Function dengan argumen berbeda
let pesanan1 = hitungTotal(25000, 3);
let pesanan2 = hitungTotal(15000, 2);

alert("Pesanan 1 -> " + pesanan1 + "\nPesanan 2 -> " + pesanan2);

Logika di Memori Sudah Siap.
Saatnya Menghidupkan Halaman Web!

Semua konsep sebelumnya (variabel, kondisi, loop, fungsi) hanyalah perhitungan abstrak di memori CPU. Sekarang, kita gunakan logika tersebut untuk mengubah teks, warna, struktur, dan tampilan website secara langsung melalui antarmuka DOM.

Sisi Otak (Core Logic)

Menghitung rumus diskon, memvalidasi nomor telepon, menyimpan keranjang belanja di memori.

Sisi Tangan (DOM API)

Mencari tombol checkout di HTML, mengubah angka total di layar, menampilkan notifikasi sukses.

09. Konsep DOM
10 / 17

DOM = Pohon Representasi Dokumen HTML

Setiap tag HTML dimuat oleh browser ke dalam struktur pohon objek yang saling terhubung (Node Tree).

Dokumen HTML Mentah 
<body>
  <header>
    <h1 id="judul">Bootcamp ITSENJA</h1>
  </header>
  <main>
    <button class="btn-aksi">Daftar</button>
  </main>
</body>
Hirarki Node Tree di Memori:
document
 └── <html>
     └── <body>
         ├── <header>
         │    └── <h1> #judul
         └── <main>
              └── <button> .btn-aksi
Kunci Utama: Setiap node di dalam pohon dokumen memiliki properti dan method bawaan yang bisa kita panggil dari JavaScript untuk dibaca atau dimodifikasi nilainya.

11. Manipulasi DOM 02
12 / 17

querySelector — Selector Se-Fleksibel CSS

Method modern standar industri untuk mengambil elemen apapun menggunakan syntax CSS selector: ID (#id), Class (.class), atau Tag (p).

Edit Kode Selector di Bawah Editable ✎ 
let elemen = document.querySelector(".box-target");
elemen.innerText = "Ketemu lewat selector class '.box-target'! 🎯";

13. Form Input Data

Membaca Nilai Input via .value

Elemen <input> dan <textarea> tidak menggunakan innerText, melainkan properti khusus .value.

  alert("Halo " + namaUser + "! Selamat datang di sesi interaktif DOM ITSENJA 🚀");
