JavaScript:
Bikin Web Jadi Hidup.

HTML itu tulang. CSS itu baju. JavaScript itu otot & saraf — yang bikin halaman web bisa gerak, respon, dan mikir.

→ tekan panah kanan / klik area kosong / spasi untuk lanjut · kotak kode bisa diklik & diedit langsung ✎

Pengantar

JavaScript itu apa, singkatnya?

Bahasa pemrograman

yang jalan di dalam browser — beda dari bahasa lain yang butuh di-install/compile dulu.

Kerja bareng HTML & CSS

HTML = struktur, CSS = tampilan, JS = perilaku & interaksi.

Itu aja dulu yang perlu diinget. Sisanya kita pelajari sambil praktik langsung.

Pengantar

Cara menghubungkan JS ke HTML.

cara 1 — inline (langsung nulis di HTML)
<body>
  ...konten halaman...

  <script>
    alert("Halo!");
  </script>
</body>
cara 2 — file terpisah (lebih rapi)
<body>
  ...konten halaman...

  <script src="app.js"></script>
</body>

taruh <script> sebelum </body> — biar HTML-nya sudah ada duluan sebelum JS mulai jalan & nyari elemen

Basic · 01

Kita mulai dari yang langsung keliatan.

Bukan teori dulu. Ubah teks di bawah lalu jalankan kodenya!

klik & edit kode di bawah ini
alert("Halo, dunia web!");

Basic · 02

Variabel = kotak penyimpanan.

klik & edit variabel di bawah
let nama = "Budi";
let umur = 17;
alert("Nama: " + nama + ", Umur: " + umur);

string

teks — selalu diapit tanda kutip "..."

number

angka — tanpa tanda kutip

boolean

cuma dua kemungkinan: true / false

Basic · 03

Program yang bisa mengambil keputusan.

coba ganti angka nilainya (misal jadi 60)
let nilai = 75;

if (nilai >= 70) {
  alert("Lulus dengan nilai: " + nilai);
} else {
  alert("Belum lulus, nilai kamu: " + nilai);
}
live demo — ganti angka di atas lalu klik jalankan
Basic · 04

Ngerjain hal berulang, tanpa nulis ulang.

coba ubah batas i <= 5 jadi 3 atau 10
let hasil = "";
for (let i = 1; i <= 5; i++) {
  hasil += "Absen ke-" + i + "\n";
}
alert(hasil);
Basic · 05

Bungkus logika jadi alat pakai ulang.

ubah nama di dalam pemanggilan sapa(...)
function sapa(nama) {
  alert("Halo, " + nama + "!");
}

sapa("Ani");
sapa("Budi");
live demo
Transisi

Otak-nya udah siap.
Sekarang saatnya ngobrol ke halaman web.

Semua yang tadi (variabel, kondisi, fungsi) itu cuma logika di kepala. Sekarang kita pakai buat ngubah tampilan web beneran — lewat sesuatu namanya DOM.

DOM · 01

DOM = peta dari halaman HTML yang bisa diutak-atik JS.

<body>
  <h1 id="judul">Halo</h1>
  <button>Klik</button>
</body>
body ├── h1 #judul └── button

setiap tag HTML = satu "node" yang bisa dipanggil dari JS

DOM · 02

Ambil elemen, lalu ubah isinya.

edit teks di dalam tanda kutip "..." di bawah
document.getElementById("playbox").innerText = "halo saya";
live sandbox — target: #playbox
Halo, saya teks biasa
DOM · 03

querySelector — Ambil elemen pakai CSS Selector.

Lebih fleksibel dari getElementById. Bisa pakai ID (#box), Class (.box), atau Tag.

edit kode di bawah untuk mengubah elemen .box
document.querySelector(".box").innerText = "Ketemu lewat querySelector! 🔍";
live sandbox — target: .box
Cari saya lewat class-nya (.box)
DOM · 04

Bukan cuma teks — tampilannya juga bisa.

coba ganti warna background & text-nya (misal: "red", "yellow", "blue")
let box = document.getElementById("playbox2");
box.style.background = "#111";
box.style.color = "#5eead4";
box.innerText = "Sekarang tampilannya berubah! 🌙";
live sandbox — target: #playbox2
Kotak ini nunggu diubah warnanya
DOM · 05

Baca input user lewat .value.

edit logika sapaan di bawah
let teksInput = document.getElementById("kotakNama").value;
if (teksInput === "") {
  alert("Isi nama kamu dulu di kotak input!");
} else {
  alert("Halo, " + teksInput + "! Selamat belajar JS!");
}
live sandbox — ketik sesuatu di input box dulu

.innerText buat elemen teks (div, h1, p) · .value khusus buat tag <input>

DOM · 06

Respon aksi pengguna (EventListener).

edit logika penambahan angkanya di bawah
let counterEl = document.getElementById("counterVal");
let angkaSekarang = Number(counterEl.innerText);
counterEl.innerText = angkaSekarang + 1;
live sandbox — target: #counterVal

Tantangan

Sekarang giliran kalian. Pilih satu:

  1. 1
    Pengubah Warna — tombol yang ganti warna background halaman tiap diklik.
  2. 2
    Penghitung Klik — kayak demo tadi, tapi tambah tombol "reset ke 0".
  3. 3
    Kotak Salam — input nama, tombol "Sapa", teks di bawahnya berubah jadi "Halo, [nama]!".

bergantian device — satu ngetik, yang lain lihat & kasih ide

Selesai

Itu aja JS dasar + DOM hari ini.

Variabel, kondisi, function → itu otaknya. getElementById / querySelector, innerText, .value, addEventListener → itu tangannya buat nyentuh halaman web. Minggu depan kita gabungin jadi satu mini-project utuh.
