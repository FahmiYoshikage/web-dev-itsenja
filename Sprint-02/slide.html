Sprint 02 · Styling & Responsive Design

CSS3 & Modern Responsive Web Design

Mengubah kerangka HTML menjadi antarmuka visual yang estetik, terstruktur, dan responsif di berbagai perangkat menggunakan CSS3, The Box Model, Flexbox, CSS Grid, dan Media Queries.

Capaian Pembelajaran

  • Memahami peran Cascading Style Sheets (CSS) dan hirarki spesifisitas.
  • Menguasai The Box Model (Margin, Border, Padding, Content).
  • Membangun layout fleksibel menggunakan Flexbox dan CSS Grid modern.
  • Merancang website responsif multi-device dengan Media Queries.

01. Konsep CSS
02 / 18

Separation of Concerns: HTML vs CSS

Prinsip arsitektur web terbaik memisahkan antara Struktur Konten (HTML) dengan Gaya Visual (CSS).

Peran Dokumen HTML

  • Menyusun judul, teks, gambar, form, dan tautan.
  • Memberikan makna semantik pada setiap bagian halaman.
  • Tidak mengurusi warna, ukuran font, atau animasi.

Peran Dokumen CSS

  • Menentukan palet warna, tipografi, dan spasi.
  • Mengatur letak kolom, grid, dan navigasi navbar.
  • Menyesuaikan tampilan di smartphone, tablet, dan laptop.
Keuntungan: Satu file style.css dapat digunakan untuk mengubah tampilan ribuan halaman website secara serempak hanya dengan satu kali edit.
02. Integrasi CSS
03 / 18

3 Cara Menghubungkan CSS ke Dokumen HTML

Pahami metode penulisan CSS dan urutan prioritasnya (Cascading Specificity):

1. Inline CSS

Ditulis di dalam atribut elemen HTML.

<p style="color: red;">Teks</p> Kurang disarankan untuk project besar.
2. Internal CSS

Ditulis di dalam tag <style> pada <head>.

<style>
  p { color: blue; }
</style> Cocok untuk halaman tunggal khusus.
3. External CSS (Standar)

File terpisah .css dihubungkan via <link>.

<link rel="stylesheet" href="style.css"> Metode terbaik & standar industri!
03. CSS Selectors
04 / 18

CSS Selectors: Menargetkan Elemen Sasaran

Selector memberi tahu browser elemen HTML mana yang ingin kita beri gaya visual.

Element Selector

Menargetkan semua tag sejenis.

p { color: #333; }
Class Selector (.)

Menargetkan kelas yang bisa diulang.

.btn-primary { ... }
ID Selector (#)

Menargetkan 1 elemen unik.

#hero-header { ... }
Pseudo-Class (:)

State dinamis interaksi.

button:hover { ... }
04. Box Model
05 / 18

The CSS Box Model: Ruang & Dimensi Elemen

Setiap elemen HTML di layar dianggap sebagai sebuah kotak persegi yang memiliki 4 lapisan lapisan ruang:

MARGIN (Jarak luar ke elemen lain)
BORDER (Garis batas bingkai)
PADDING (Jarak dalam antara isi & border)
CONTENT (Teks / Gambar Aktual)

Aturan Wajib CSS Reset:

Secara default, penambahan padding memperbesar lebar total elemen. Gunakan aturan box-sizing: border-box agar padding dihitung di dalam ukuran lebar yang sudah ditentukan:

* {
  box-sizing: border-box;
  margin: 0;
  padding: 0;
}

08. Flexbox Layout
09 / 18

Modern Layouting: CSS Flexbox (1 Dimensi)

Flexbox dirancang untuk menata elemen dalam 1 arah (baris horizontal atau kolom vertikal) secara fleksibel.

1. Display & Direction

• display: flex; (aktifkan flex)
• flex-direction: row | column;

2. Alignment (Sumbu Utama & Silang)

• justify-content: space-between | center;
• align-items: center;

3. Spacing & Wrap

• gap: 16px; (jarak otomatis antar item)
• flex-wrap: wrap; (turun ke baris baru)

10. CSS Grid Layout
11 / 18

Modern Layouting: CSS Grid (2 Dimensi)

CSS Grid dirancang untuk mengatur baris dan kolom secara bersamaan dengan kontrol presisi tinggi.

Fraction Unit (fr)

Membagi ruang kosong secara proporsional.
grid-template-columns: 1fr 1fr 1fr;

Auto-Fit & MinMax

Otomatis responsif tanpa media query!
repeat(auto-fit, minmax(200px, 1fr))

Gap Spacing

Jarak antar sel horizontal & vertikal.
gap: 16px;

12. Media Queries
13 / 18

Responsive Design: Media Queries

Media queries memungkinkan kita menerapkan aturan CSS yang berbeda sesuai ukuran layar pengguna.

Contoh Sintaks Media Query:

/* Tampilan Normal (Desktop) */
.container { display: flex; }

/* Tampilan Smartphone (Layar ≤ 768px) */
@media (max-width: 768px) {
  .container { flex-direction: column; }
}

Breakpoint Standar Industri:

  • Mobile: < 640px
  • Tablet: 640px - 1024px
  • Desktop / Laptop: > 1024px
