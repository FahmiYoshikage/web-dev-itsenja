API

Apa itu API?

API (Application Programming Interface) adalah antarmuka yang memungkinkan software berkomunikasi dengan software atau layanan lain melalui aturan tertentu.

Analogi: frontend seperti pelanggan, API seperti pelayan, dan server seperti dapur. Frontend meminta sesuatu melalui API; server memproses lalu mengembalikan response.

API FLOW

Alur komunikasi Client ↔ Server

Browser mengirim HTTP request ke endpoint API. Server memproses request dan mengembalikan HTTP response.

Client → Request → API/Server → Response → Client. Untuk sprint ini fokus utama kita adalah GET, yaitu mengambil data.

API ANATOMY

Kenali bagian-bagian API.

Endpoint adalah alamat resource. HTTP method menjelaskan operasi. Request adalah informasi yang dikirim client. Response adalah hasil dari server.

GET = mengambil, POST = membuat, PUT/PATCH = mengubah, DELETE = menghapus. Contoh endpoint: https://api.example.com/users

HTTP

Response punya status.

HTTP status membantu kita mengetahui hasil request.

200 OK = berhasil. 404 Not Found = resource tidak ditemukan. 500 Server Error = masalah di server. Jangan menganggap semua request pasti berhasil.

JSON

Data API sering dikirim sebagai JSON.

JSON (JavaScript Object Notation) adalah format pertukaran data berbasis teks yang mudah dibaca manusia dan diproses program.

Object JSON: { "name": "Fahmi", "role": "Student" }. Array JSON dapat berisi banyak object. JSON adalah format data, bukan pengganti JavaScript.

FETCH

Fetch API: membuat HTTP request

Fetch API adalah API browser yang digunakan JavaScript untuk melakukan network request.

Contoh: fetch(url).then(response => response.json()).then(data => console.log(data)); Fetch mengembalikan Promise.

PROMISE

Kenapa muncul Promise?

Network request membutuhkan waktu. Hasilnya tidak selalu tersedia pada saat baris kode dijalankan.

Promise merepresentasikan hasil operasi asynchronous yang belum selesai. Keadaan sederhananya: Pending → Fulfilled atau Rejected.

ASYNC AWAIT

Tuliskan asynchronous code dengan lebih nyaman.

async menandai function sebagai asynchronous. await menunggu hasil Promise di dalam function tersebut.

const response = await fetch(url); const data = await response.json();. async/await bukan membuat network request menjadi synchronous; ia hanya membuat penulisannya lebih mudah dibaca.

FETCH FULL

HTML + CSS + JS: Fetch pertama.

Kita tidak hanya melihat potongan JS. Lihat struktur lengkapnya: HTML menyediakan target, CSS mengatur tampilan, JavaScript mengambil data dan mengubah DOM.

Coba jalankan demo di sebelah kanan. Setelah berhasil, ubah teks, selector, atau endpoint lalu jalankan lagi.

BREAKDOWN

Pahami alur data.

fetch(url) → Response → response.json() → JavaScript data → proses data → DOM.

fetch() mengambil response. response.json() membaca body JSON secara asynchronous. Setelah menjadi data JavaScript, kita dapat melakukan forEach/map/filter lalu merender hasilnya.

RESPONSE

Response bukan langsung data.

Object yang diterima dari fetch adalah Response. Kita perlu memeriksa status sebelum membaca body.

const response = await fetch(url); if (!response.ok) throw new Error('Request gagal'); const data = await response.json();. Ini membedakan response HTTP dengan data payload.

ERROR

Request bisa gagal. Gunakan try/catch.

Aplikasi harus memikirkan kondisi gagal, bukan hanya kondisi sukses.

try { ... } catch (error) { ... }. Gunakan response.ok untuk memeriksa status HTTP. Tampilkan feedback yang jelas kepada pengguna.

UI STATES

API membutuhkan state.

Minimal kenali tiga keadaan: Loading, Success, dan Error.

Loading memberi tahu request sedang berjalan. Success menampilkan data. Error memberi tahu pengguna bahwa data gagal diambil. Ini adalah bagian dari UX, bukan sekadar tambahan.

ARRAY

API biasanya mengembalikan banyak object.

Karena response sering berupa array, kita perlu memproses kumpulan data.

Gunakan forEach() untuk melakukan aksi pada setiap item. Gunakan map() ketika ingin menghasilkan array baru. Gunakan filter() ketika ingin menyaring data.

RENDER

Dari data menjadi UI.

Data yang sudah diterima belum otomatis tampil di halaman. JavaScript harus menghubungkan data dengan DOM.

Contoh pola: data.forEach(item => { const card = document.createElement('article'); card.textContent = item.name; container.appendChild(card); });

DEVTOOLS

Belajar API dengan Network & Console.

DevTools adalah alat utama untuk memahami apa yang sebenarnya terjadi.

Network: lihat URL, method, status, response, dan timing. Console: cek data dan error. Workflow: request benar? status benar? response benar? parsing benar? data benar? DOM benar?
