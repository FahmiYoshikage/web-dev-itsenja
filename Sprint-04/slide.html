API (Application Programming Interface) adalah jembatan komunikasi antara Frontend dan Server.

📱
Frontend (Pelanggan)
Duduk di meja, melihat menu, dan memesan makanan lewat pelayan.
🤵‍♂️
API (Pelayan)
Membawa pesanan ke dapur, lalu mengantarkan makanan kembali ke meja pelanggan.
🍳

LOGIKA ASYNC

Kenapa Butuh Async / Promise?

Mengambil data dari internet butuh waktu (koneksi lemot, jarak server). JS tidak boleh diam membeku (*freeze*) saat menunggu.

🥪 Analogi Pesan Kopi (Asynchronous)

Kamu pesan kopi di kasir $\rightarrow$ Dikasih struk/nomor antrian (Promise) $\rightarrow$ Kamu bisa santai main HP dulu $\rightarrow$ Saat kopi siap, nomormu dipanggil (Resolved).

⏳ 3 Status Promise

  • Pending: Sedang menunggu balasan server.
  • Fulfilled / Resolved: Berhasil dapat data.
  • Rejected: Gagal (misal: internet putus).

PENGALAMAN PENGGUNA (UX)

3 State Utama Aplikasi Web: Loading, Success, Error

Aplikasi standar industri yang baik selalu memiliki 3 kondisi visual:

1. Loading State ⏳

Beri tahu user bahwa sistem sedang bekerja (spinner / teks loading / skeleton).

2. Success State ✅

Data bersih berhasil dirender ke elemen-elemen HTML (Card / Tabel).

3. Error State ❌

Pesan kesalahan yang manusiawi plus tombol "Coba Lagi" (Retry).

RANGKUMAN

Rumus Sakti Fetch API

Hafalkan pola sederhana 6 langkah ini untuk semua jenis web API di masa depan:

1. Tampilkan Loading UI
2. const res = await fetch(url);
3. Periksa status if (!res.ok) throw ...
4. const data = await res.json();
5. Olah data dengan data.forEach(...)
6. Render ke DOM & sembunyikan Loading!
