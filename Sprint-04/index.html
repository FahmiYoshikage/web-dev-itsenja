02. Memahami API
03 / 18

Apa itu API (Application Programming Interface)?

API adalah jembatan komunikasi antara aplikasi frontend (browser kamu) dengan server penyimpan data.

🍽️ Analogi Restoran: Bagaimana API Bekerja?

🧑 Client (Kamu) Duduk di meja, pilih menu & pesan
➔
🔌 API (Pelayan) Mencatat & bawa pesanan ke dapur
➔
🖥️ Server (Dapur)Memasak & menyiapkan data
📦 Data (Makanan)Hasil masakan dari dapur
⬅
🔌 API (Pelayan)Mengantar makanan ke meja
⬅
🧑 Client (Kamu)Menikmati hidangan di browser
Kesimpulan: Frontend tidak perlu tahu bagaimana database server bekerja. Frontend cukup meminta ke API, dan API akan membawakan data yang diminta.
03. Bagian API
04 / 18

Anatomi Komunikasi Request & Response

Ketika browser meminta data ke API, komunikasi selalu terdiri dari 4 elemen kunci berikut:

1. Endpoint (URL)

Alamat spesifik tujuan request.
Contoh: https://api.com/users

2. HTTP Method

Aksi yang dilakukan:
• GET: Ambil Data
• POST: Kirim Data Baru
• DELETE: Hapus Data

3. Request Header/Body

Informasi tambahan dari client seperti Token Keamanan atau format data yang dikirim.

4. HTTP Response

Hasil balasan dari server yang berisi Status Code dan Data (JSON).

200 OK Berhasil! Data siap digunakan.
404 Not Found Alamat Endpoint tidak ditemukan.
500 Server Error Terjadi kendala pada server backend.

05. Async Flow
06 / 18

Sync vs Asynchronous Execution

Mengapa Asynchronous itu krusial? Mengambil data dari internet butuh waktu (misal 1-3 detik). Jangan sampai seluruh tampilan browser membeku saat menunggu!

Synchronous (Blocking)

Baris 2 menunggu baris 1 selesai total. Jika proses baris 1 lambat (e.g., download gambar besar), browser akan mengunci layar dan pengguna tidak bisa mengklik apa pun.

console.log("Baris 1");
ambilDataLama(); // Blocking 5 detik!
console.log("Baris 3");

Asynchronous (Non-Blocking)

JavaScript menyuruh proses lambat berjalan di "latar belakang". Kode di bawahnya langsung dieksekusi tanpa menunggu. Hasilnya akan dikabarkan ketika sudah siap!

console.log("Mulai");
fetchDataAsync(); // Berjalan di background
console.log("Selesai (Langsung jalan!)");
⚡ Catatan Penting: JavaScript secara default bersifat single-threaded. Mekanisme Asynchronous memungkinkan JavaScript menangani tugas berat dengan mulus tanpa lag.
06. JavaScript Promise
07 / 18

Memahami Promise (Janji Async)

Promise adalah objek JavaScript yang mewakili hasil dari operasi asynchronous — yang statusnya mungkin belum selesai saat ini, tapi akan selesai di masa depan.

1. Pending

Sedang memproses / menunggu respon dari jaringan.

2. Fulfilled (Resolved)

Janji ditepati! Data berhasil didapatkan.

3. Rejected

Janji gagal! Terjadi error atau koneksi terputus.
